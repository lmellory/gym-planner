# 🏋️ Gym Planner — Ежедневник тренера: Telegram Mini App

Telegram Mini App + бот-ассистент для тренера в тренажёрном зале, персонального фитнес-инструктора и тренера групповых программ.  
Работает 24/7 в бессерверном облаке **Cloudflare Workers** с распределённой базой данных **Turso (libSQL/SQLite)**.

---

## ⚡ Возможности

- **📅 Полоса недели со свайпом (Пн–Вс)**:
  - Быстрое переключение между днями недели.
  - Индикация запланированных тренировок цветными точками и значок 📝 при наличии заметок тренера на этот день.
- **✨ Свободные окна дня**:
  - Автоматический расчёт и визуальные бейджи свободных слотов с учётом рабочего графика тренера и уже назначенных занятий.
  - Клик по свободному окну мгновенно открывает форму записи на это время.
- **🏋️ Запись на тренировки**:
  - Быстрый выбор времени начала занятия.
  - **Виды занятий** (с индивидуальной длительностью по умолчанию, которую можно изменить в один клик):
    - 🏋️ **Персональная тренировка** (`personal`, 60 мин)
    - 👥 **Сплит-тренировка** (`split`, 60 мин, на 2–3 человека)
    - 🤸 **Групповое занятие** (`group`, 60 мин)
    - ⚡ **Пробное занятие** (`trial`, 45 мин)
    - 📋 **Консультация / замеры** (`consultation`, 30 мин — составление программы, замеры, разбор питания)
    - 💻 **Онлайн-тренировка** (`online`, 60 мин — онлайн-ведение или разбор техники)
  - Поле **«Кто это / участники»** (`who`): удобно перечислить участников группы/сплита или отметить источник записи (зал, рекомендация, соцсети).
  - Автоматическая проверка интервальных пересечений $[start, end)$ с понятным предупреждением о накладках по времени.
  - Автоподстановка клиентов из базы при вводе имени.
  - **Статусы записи**: *Запланирована* / *Не пришёл* / *Отменена*. Статусы «Не пришёл» и «Отменена» освобождают время в графике (не дают конфликтов по времени и не считаются в расписании бота).
  - Сорванные и отменённые занятия выделяются в карточках и не включаются в фактический доход.
- **💰 Доходы и прайс услуг**:
  - Указание стоимости тренировки (необязательное поле).
  - **Прайс услуг** (Настройки → «Прайс услуг»): базовые цены по видам занятий автоматически подставляются в новую запись и при смене вида тренировки, не затирая введённую вручную сумму.
  - **Раздел «Доходы»** (иконка графика в шапке): наглядные диаграммы и финансовые итоги за неделю, месяц и год, подсчёт среднего чека тренировки и сравнение с прошлым периодом.
  - Разделение на фактический доход (состоявшиеся тренировки) и ожидаемый доход (будущие тренировки).
  - Валюта задаётся константой `CURRENCY` в начале `webapp/app.js`.
- **🧾 Учёт расходов и чистая прибыль**:
  - Каждая трата фиксируется как отдельная запись (дата, статья расходов, сумма).
  - **Траты по статьям**: аренда зала, спортивный инвентарь, спортивное питание и добавки, обучение и курсы, реклама.
  - Переключатель «Доход / Траты» на экране финансов с автоматическим расчётом чистой прибыли за период.
  - Список всех трат с возможностью добавления, редактирования и удаления.
- **👥 База клиентов (атлетов)**:
  - Карточки клиентов с поиском по имени и контактам.
  - Номер телефона с быстрым звонком и кликабельная ссылка на профиль Telegram.
  - Индивидуальные заметки тренера: спортивные цели, травмы, противопоказания, ограничения по нагрузкам, рабочие веса и особенности подопечного.
  - 🎂 **День рождения клиента**: указание даты (число и месяц), праздничный бейдж и **автоматическое напоминание тренеру в 10:00 утра** (по часовому поясу тренера) со всеми контактами именинника для поздравления.
  - История всех тренировок подопечного и кнопка быстрой записи на следующую тренировку.
- **📝 Заметки тренера на день**:
  - Планы тренировочного дня, дежурства в зале, закупки инвентаря и напоминания. Мгновенно дублируются сообщением тренеру в Telegram.
- **🔔 Уведомления и бот-ассистент**:
  - Мгновенные уведомления о добавлении тренировок (с автоматической очисткой сервисных сообщений из чата через сутки, чтобы не засорять переписку).
  - **🌙 Вечернее расписание**: бот каждый вечер (по умолчанию в 22:00) присылает компактное расписание на завтра со списком атлетов, временем занятий, контактами (телефон / Telegram) и заметкой тренера.
- **⚙️ Настройки рабочего графика**:
  - Выбор рабочих дней (Пн–Вс), начала и окончания рабочего дня тренера, часового пояса и времени вечернего уведомления.
- **💾 Резервные копии и безопасность**:
  - **Еженедельный автоматический бэкап**: каждое воскресенье в 21:00 бот присылает JSON-файл в личный чат тренера (все тренировки, клиенты, траты, прайс, заметки, настройки).
  - Кнопка «Резервная копия сейчас» в настройках.
  - **Восстановление из копии** (JSON): валидация файла, предварительный отчёт «что будет восстановлено» и атомарная замена данных в одной транзакции (при любой ошибке данные не ломаются).
  - **📊 Экспорт в Excel / CSV**: безопасная выгрузка тренировок, доходов и расходов в файл CSV (UTF-8 с BOM, корректные телефонные номера с `+` и экранирование от CSV-инъекций) прямо в чат Telegram.
- **🎨 Дизайн и эргономика**:
  - Современный спортивный интерфейс в тёплой оранжевой палитре.
  - Полная поддержка тёмной и светлой тем Telegram.
  - Оптимизирован для быстрого управления одной рукой со смартфона прямо между подходами в зале.
  - Защита от случайного закрытия свайпом (`disableVerticalSwipes`) и защита от гонок запросов (`AbortController` + `requestId`).

## 🛠 Стек технологий

- **Бэкенд**: Cloudflare Workers, TypeScript, [Hono](https://hono.dev/).
- **База данных**: [Turso](https://turso.tech/) (libSQL / SQLite) через `@libsql/client/web` (атомарные транзакции `batch`).
- **Фронтенд**: Чистый JavaScript (Vanilla), HTML5, CSS3 без тяжёлых фреймворков и сборщиков.
- **Telegram WebApp**: BackButton, MainButton, HapticFeedback, showConfirm, disableVerticalSwipes.
- **Фоновые задачи**: Cloudflare Cron Triggers (`* * * * *`): проверка вечерних расписаний, поздравлений с ДР, еженедельных копий и удаление временных сервисных сообщений.
- **Тесты**: [Vitest](https://vitest.dev/) (`npm test`): подпись Telegram, валидация данных, расчёт временных слотов, интеграционные тесты API и миграций на настоящей SQLite, тестирование UI в jsdom.

## 🚀 Быстрый запуск и деплой

### 1. Установка зависимостей
```bash
npm install
```

### 2. Секреты Cloudflare
Задаются через команду `wrangler secret put`:
```bash
npx wrangler secret put BOT_TOKEN        # Токен бота от @BotFather
npx wrangler secret put ALLOWED_IDS      # Telegram ID тренеров через запятую
npx wrangler secret put WEBHOOK_SECRET   # Секретная строка для защиты вебхука
npx wrangler secret put TURSO_AUTH_TOKEN # Токен доступа к базе Turso
```

Переменная `TURSO_URL` и адрес приложения `APP_URL` указываются в `wrangler.toml` (или в `.dev.vars` для локальной разработки).

### 3. Автоматическое применение миграций к Turso
В проект встроен скрипт применения миграций:
```bash
npm run migrate
```
Скрипт проверяет таблицу `schema_migrations` в Turso и применяет только недостающие файлы:
- `0001_init.sql` — начальная структура базы
- `0002_notify_22.sql` — расписание вечерних уведомлений
- `0003_schema_hardening.sql` — нормализация схемы и создание `schema_migrations`
- `0004_notify_options.sql` — параметры уведомлений и таблица `scheduled_deletes`
- `0005_optional_end_time.sql` — опциональный `end_time`
- `0006_clients_and_schedule.sql` — таблица клиентов `clients` и график работы в `users`
- `0007_client_birthdays.sql` — дни рождения клиентов и утренние напоминания
- `0008_service_fingers.sql` — поддержка дополнительных параметров услуг
- `0009_price.sql` — базовый прайс
- `0010_expenses.sql` — учёт расходов по статьям
- `0011_prices_and_backup.sql` — расширенный прайс и еженедельные копии
- `0012_status_free_service.sql` — статусы тренировок (`scheduled`, `cancelled`, `missed`)
- `0013_access.sql` — управление доступом (`/adduser`, `/ban`, `/unban`)
- `0014_user_names.sql` — имя и @username пользователя для админ-панели
- `0015_gym_sessions.sql` — структура для фитнес-тренировок в спортзале (удаление ногтевых колонок, адаптация таблицы `appointments`)

### 4. Тесты и проверка типов
```bash
npm test
npm run typecheck
```

### 5. Деплой приложения
```bash
npm run deploy
```

### 6. Установка Webhook Telegram
```bash
curl "https://api.telegram.org/bot<BOT_TOKEN>/setWebhook" \
  -d "url=https://<WORKER_URL>/webhook" \
  -d "secret_token=<WEBHOOK_SECRET>"
```

## 💬 Команды бота

### Основные команды тренера
- `/start` / `/menu` — приветствие, справка и кнопка открытия Mini App.
- `/today` — расписание тренировок на сегодня.
- `/tomorrow` — расписание тренировок на завтра.
- `/notify` — принудительно сформировать и прислать вечернее расписание на завтра.
- `/id` — узнать свой числовой Telegram ID.

---

### 🛠 Команды администратора

Доступны только администраторам (указываются в `ADMIN_ID` в `wrangler.toml` через запятую). Обычным пользователям бот на эти команды не отвечает.

| Команда | Описание |
| --- | --- |
| `/admin` | список всех доступных команд администратора |
| `/users` | список пользователей в базе: статус доступа (✅/⛔), число тренировок, клиенты, дата последней активности |
| `/user ID` | карточка тренера: доступ, объёмы данных, доход за месяц, настройки графика и копий |
| `/stats` | общая сводка по всей базе: число тренеров, тренировок (сегодня, завтра, впереди), база клиентов, траты |
| `/health` | проверка здоровья сервиса: пинг Turso, миграции, статус бота (`getMe`), состояние очереди webhook |
| `/export` | список тренеров и число их тренировок |
| `/records` | все записи всех тренеров за всё время одним CSV-файлом (открывается в Excel) |
| `/records ID` | выгрузка всех записей конкретного тренера в CSV |
| `/export ID` | прислать в чат CSV и полный JSON-бэкап данных выбранного тренера |
| `/backupall` | прислать резервную JSON-копию каждого пользователя базы |
| `/send ID текст` | отправить сервисное сообщение тренеру от имени бота |
| `/broadcast текст` | массовая рассылка сообщения всем пользователям с активным доступом |
| `/adduser ID` | открыть доступ новому тренеру |
| `/ban ID` | заблокировать доступ тренеру (данные остаются в базе) |
| `/unban ID` | разблокировать тренера |

> **Примечание по доступу**: Итоговый доступ = (`ALLOWED_IDS` + выданные через `/adduser`) за вычетом заблокированных через `/ban`.

#### 🛠 Админ-панель в Mini App
У администратора в шапке приложения отображается кнопка 🛠. Она открывает список тренеров с числом тренировок. При выборе тренера включается режим «правка за тренера» (заголовок `X-Act-As`): администратор может просматривать, создавать, переносить и удалять тренировки в расписании выбранного тренера. Личные финансовые показатели, заметки и настройки тренера в этом режиме скрыты.

#### 👁 Наблюдатели
ID пользователей с правами наблюдателя задаются переменной `VIEWER_IDS` в `wrangler.toml`. Наблюдатель имеет доступ только к чтению сводки (`/records` и краткий `/admin`), без права редактирования, рассылок и доступа к бэкапам.

## 🏋️ Как добавить новый вид тренировки

Виды занятий проверяются на уровне кода приложения и не требуют миграции базы данных:
1. Добавьте идентификатор в `src/lib/services.ts` (массив `SERVICES`).
2. Задайте длительность по умолчанию в `src/lib/time.ts` (функция `defaultServiceDuration`).
3. Добавьте текстовое название в словари подписей: `src/lib/format.ts` и `src/api/export.ts`.
4. Добавьте отображение в интерфейсе: кнопку выбора занятия и поле в прайсе в `webapp/index.html`, а также при необходимости подпись в `webapp/app.js`.
